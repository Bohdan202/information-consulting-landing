# ЕкомКонсалт — статичний сайт ФОП

Простий багатосторінковий сайт інформаційно-консультаційних послуг у сфері інформатизації (HTML5, CSS3, Vanilla JavaScript).

## Файли

- `index.html` — головна сторінка;
- `services.html` — перелік послуг;
- `contacts.html` — контакти та форма заявки;
- `css/style.css` — стилі й адаптивність;
- `js/script.js` — мобільне меню та валідація форми.

Перед публікацією замініть позначки `[Номер телефону]`, `[Email]`, `[Telegram]`, `[Viber]` на актуальні контактні дані. Форму підготовлено для майбутнього підключення backend або зовнішнього сервісу: наразі вона лише перевіряє введені дані у браузері та чесно повідомляє про відсутність надсилання.
